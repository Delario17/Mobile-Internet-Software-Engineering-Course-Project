## 当前边界与下一次验收

输出为16kHz单声道16位PCM WAV，上限30分钟；暂未完成响度归一化、智能裁静音、导出历史ExportRecord、其他编码格式输出。非标准WAV交由官方原生解码器，不能承诺所有编解码器可用。参考真机、飞行模式（不只是关闭WLAN）、权限永久拒绝、真实系统中断、存储不足、声音质量及小屏/无障碍验收尚未完成。
