# AudioPatch 首次使用交互改进

依据本次可用性审核与用户“更改并推送仓库”的授权执行。

范围：单文件 HTML 交互原型与设计文档；不代表已接通 HarmonyOS 录音、识别或音频导出。

- 首屏说明“录完一整段，只重录其中一句”，默认隐藏需求标注；演示工作台可折叠。
- 新建页提供带标签的原生可选输入；项目卡进入一致的工作上下文。
- 编辑页区分选中与播放状态，未选句不能重录；选句上下文贯穿改字、补录、版本比较。
- 试听和使用版本分开，采用后显示反馈，成片时长和替换数量联动；原音可恢复。
- 确认文字和声音范围分开；未完成时导出入口引导检查，所有实际导出入口仍严格拦截；修改文字使相关确认失效。
- 用用户语言描述进度、检查和音量，技术参数放到折叠详情；倒计时结束后才提示开口。
- 波形编辑等未实现的操作明确为演示，不能把页面跳转伪装为已保存。
- 保留原音保护及 P1-FR-010 审核基线。此次不降低门槛，不实现音频能力，不新增运行时依赖。

验收：浏览器操作验证未选句、跨句编辑、候选/采用区别、恢复原音、修改后重新检查、各导出入口拦截以及小屏显示。原型刷新重置示例数据，界面必须说明。
